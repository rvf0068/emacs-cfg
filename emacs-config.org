** Personal Settings

Loads an optional =personal.org= file for private configuration (paths, model settings, or credentials). The defaults are prepared afterwards, so existing =setq= and =defvar= assignments still take precedence. Without private settings, notes and PDF files use isolated directories under =local-data/= and the global bibliography is empty. See =personal.example.org= for examples.

#+begin_src emacs-lisp
;; -*- lexical-binding: t; -*-
(if (file-exists-p
     (expand-file-name "personal.org" user-emacs-directory))
    (org-babel-load-file (expand-file-name "personal.org" user-emacs-directory)))
(require 'personal-settings)
(rvf/prepare-personal-settings)
#+end_src

*** AUCTeX

*** cdlatex

[[https://staff.fnwi.uva.nl/c.dominik/Tools/cdlatex/][CDLaTeX]] is a minor mode for quickly inserting LaTeX environments and mathematical symbols in both LaTeX and Org buffers. It is particularly useful in both LaTeX and Org buffers. The =cdlatex-takeover-parenthesis= variable is customized to resolve a [[https://github.com/cdominik/cdlatex/issues/15#issuecomment-864529972][known issue]].
The following table summarizes the custom math symbol additions.

| Trigger Key | First Expansion | Second Expansion | Third Expansion     |
|-------------+-----------------+------------------+---------------------|
| =c=           | =\colon=          |                  |                     |
| =m=           | =\mu=             | =\mapsto=          |                     |
| =p=           | =\pi=             | =\varpi=           | =\perp=               |
| =o=           | =\omega=          | =\oplus=           |                     |
| =O=           | =\Omega=          | =\mathrm{Orb}=     |                     |
| =S=           | =\Sigma=          | =\mathrm{Stab}=    |                     |
| =T=           | =\bigtriangleup=  |                  |                     |
| ~-~           | =\cap=            | =\leftrightarrow=  | =\longleftrightarrow= |
| =.=           | =\ldots=          | =\cdots=           | =\cdot=               |
| =*=           | =\times=          | =\otimes=          |                     |
| =<=           | =\leq=            | =\langle=          | =\trianglelefteq=     |
| =>=           | =\geq=            | =\rangle=          | =\trianglerighteq=    |
| ~=~           | =\simeq=          | =\sim=             |                     |
| =[=           | =\subseteq=       |                  |                     |

#+begin_src emacs-lisp
(use-package cdlatex
  :straight t
  :custom
  (cdlatex-math-symbol-alist
   '(( ?c   ("\\colon"))
     ( ?m   ("\\mu" "\\mapsto"))
     ( ?p   ("\\pi" "\\varpi" "\\perp"))
     ( ?o   ("\\omega" "\\oplus"))
     ( ?O   ("\\Omega" "\\mathrm{Orb}"))
     ( ?S   ("\\Sigma" "\\mathrm{Stab}"))
     ( ?T   ("\\bigtriangleup"))
     ( ?-   ("\\cap" "\\leftrightarrow" "\\longleftrightarrow"))
     ( ?.   ("\\ldots" "\\cdots" "\\cdot"))
     ( ?*   ("\\times" "\\otimes"))
     ( ?<   ("\\leq" "\\langle" "\\trianglelefteq"))
     ( ?>   ("\\geq" "\\rangle" "\\trianglerighteq"))
     ( ?=   ("\\simeq" "\\sim"))
     ( ?\[  ("\\subseteq"))))
  (cdlatex-math-modify-alist
   '(( ?a "\\overrightarrow" nil t nil nil)
     ( ?k "\\mathfrak" nil t nil nil)
     ( ?B "\\mathbb"         nil t nil nil)))
  (cdlatex-command-alist
   '(("bin"  "Insert \\binom{}{}" "\\binom{?}{}" cdlatex-position-cursor nil nil t)
     ("norm" "Insert \\Vert \\Vert" "\\Vert ?\\Vert" cdlatex-position-cursor nil nil t)
     ("gen"  "Insert \\langle \\rangle" "\\langle ?\\rangle" cdlatex-position-cursor nil nil t)
     ("set"  "Insert a set" "\\{?\\mid \\}" cdlatex-position-cursor nil nil t)))
  (cdlatex-simplify-sub-super-scripts nil)
  (cdlatex-takeover-parenthesis nil)
  :config
  ;; CDLaTeX constructs its keymap at load time.  If it was loaded
  ;; earlier, changing the custom option alone leaves stale bindings.
  (unless cdlatex-takeover-parenthesis
    (dolist (key '("(" "{" "[" "|" "<"))
      (when (eq (lookup-key cdlatex-mode-map (kbd key)) #'cdlatex-pbb)
        (define-key cdlatex-mode-map (kbd key) nil)))))
#+end_src

*** math-delimiters

The [[https://github.com/oantolin/math-delimiters][math-delimiters]] package provides commands for inserting TeX/LaTeX math delimiters. The =$= key is bound in Org and AUCTeX LaTeX modes before the package is loaded, and unbound from =cdlatex-mode-map= where it would conflict.

#+begin_src emacs-lisp
(use-package math-delimiters
  :straight (:host github :repo "oantolin/math-delimiters")
  :commands math-delimiters-insert
  :init
  (with-eval-after-load 'org
    (define-key org-mode-map "$" #'math-delimiters-insert))
  (with-eval-after-load 'latex
    (define-key LaTeX-mode-map "$" #'math-delimiters-insert))
  (with-eval-after-load 'cdlatex
    (define-key cdlatex-mode-map "$" nil)))
#+end_src

*** math-shortcuts

This custom minor mode inserts standard number-set symbols (\(\mathbb{R}, \mathbb{Q}, \mathbb{C}, \mathbb{Z}, \mathbb{N}\)) when typing the corresponding capital letter inside a recognized math fragment. Typing the same letter immediately again replaces the expansion with the plain capital. Outside math, the mode invokes the ordinary key binding, preserving Org table editing and other insertion behavior. Use =M-x math-shortcuts-mode= to toggle the shortcut in the current buffer.

#+begin_src emacs-lisp
(require 'math-shortcuts)
(add-hook 'LaTeX-mode-hook #'math-shortcuts-mode)
(add-hook 'org-mode-hook #'math-shortcuts-mode)
#+end_src

** Org Mode

This section contains the configuration for [[https://orgmode.org][Org mode]], a powerful system for outlining, note-taking, project planning, and authoring.

This configuration loads a custom helper file, =cross-refs.el=, which defines functions to enable a smart cross-referencing system. When the preceding word does not identify a type, =C-c r= offers all document labels. The completion list uses bounded previews and merges duplicate =#+name:= and =#+label:= declarations. Historical =pf:= and =prop:= labels remain discoverable alongside =prf:= and =pro:=, without changing existing documents. New mathematical snippets insert only =#+name:=, which is sufficient for both navigation and LaTeX export.
- =my/org-insert-smart-ref= (bound to =C-c r=) intelligently guesses the type of reference to insert (e.g., `thm:`, `def:`) based on the preceding word.
- This system works with a custom set of Yasnippet snippets (bound to =<f6> <key>=) that insert theorem-like environments (see =yasnippet= section).
- The snippets use the helper function =my/org-snippet-get-unique-label= from =cross-refs.el= to prompt for a label and ensure it is not a duplicate before insertion.

The =C-c a d= dashboard combines a seven-day agenda with open TODOs across configured agenda files. Use =C-c c i= to capture tasks and =C-c c w= to capture web pages; during a daily review, turn inbox items into actionable tasks and schedule only work that has a real date.

#+begin_src emacs-lisp
(use-package org
  ;; Already registered by init.el before Org tangles this file.
  :straight nil
  :demand t
  :bind
  ("C-c a" . org-agenda)
  ("C-c c" . org-capture)
  :bind (:map org-mode-map
              ("C-c r" . my/org-insert-smart-ref))
  :init
  (require 'org-habit)
  (require 'org-protocol)
  :config
  (add-to-list 'org-src-lang-modes '("python-cell" . python))
  ;; Helper macro for backend-specific code
  (defmacro by-backend (&rest body)
    `(cl-case org-export-current-backend ,@body))

  ;; Cross references in org mode
  (require 'cross-refs)

  ;; GTD system and Inbox.org creation
  ;; Do not create an Inbox or modify a database on a missing mount.
  (unless (boundp 'org-capture-templates)
    (setq org-capture-templates nil))
  (defun rvf/set-gtd ()
    "Set agenda and templates for GTD"
    (unless (rvf/notes-directory-ready-p)
      (user-error "Notes directory unavailable: %s" my-notes-directory))
    (let ((inbox (expand-file-name "Inbox.org" my-notes-directory)))
      (unless (file-exists-p inbox)
        (write-region "" nil inbox nil 'silent nil 'excl)))
    (add-to-list 'org-agenda-files
                 (expand-file-name "Inbox.org" my-notes-directory))
    (add-to-list 'org-capture-templates
                 `("i" "Inbox" entry
                   (file ,(expand-file-name "Inbox.org" my-notes-directory))
                   ,(concat "* TODO %?\n"
                            "/Entered on/ %U")))
    (add-to-list 'org-capture-templates
                 `("w" "web" entry
                   (file+headline ,(expand-file-name "Inbox.org" my-notes-directory) "Web")
                   "* %a\n\n%U\n%i%?")))
  (if (rvf/notes-directory-ready-p)
      (rvf/set-gtd)
    (display-warning 'rvf-personal "Skipping Inbox setup: notes directory unavailable" :warning))
  ;; A compact review view: scheduled work for the next week and open TODOs
  ;; across the configured agenda files.
  (setq org-agenda-custom-commands
        '(("d" "Dashboard"
           ((agenda "" ((org-agenda-span 7)))
            (todo "TODO"
                 ((org-agenda-overriding-header "Open TODO tasks"))))))
        org-agenda-start-on-weekday nil
        org-deadline-warning-days 7
        org-agenda-skip-deadline-if-done t
        org-agenda-skip-scheduled-if-done t)
  ;; Font scaling for better readability
  (set-face-attribute 'org-level-1 nil :height 1.5)
  (set-face-attribute 'org-level-2 nil :height 1.3)
  (set-face-attribute 'org-level-3 nil :height 1.2)
  (set-face-attribute 'org-level-4 nil :height 1.1)
  (set-face-attribute 'org-document-title nil :height 1.75)
  :custom
  ;; Note: 'my-bibliography' is set in personal.org
  (org-cite-global-bibliography (rvf/bibliography-files))
  ;; LaTeX/PDF use biblatex's default style (via latexmk+biber); other
  ;; backends (HTML, Markdown, ...) keep org-cite's built-in "basic" style.
  (org-cite-export-processors
   '((latex biblatex)
     (t basic)))
  (org-export-with-tags nil)
  (org-beamer-environments-extra
   '(("lemma" "l" "\\begin{lemma}%a[%h]%l" "\\end{lemma}")
     ("corollary" "c" "\\begin{corollary}%a[%h]%l" "\\end{corollary}")))
  (org-file-apps
   '((auto-mode . emacs)
     ("pdf" . "evince %s")))
  (org-hide-emphasis-markers t)
  (org-latex-compiler "pdflatex")
  (org-log-done 'note)
  (org-return-follows-link t)
  (org-src-preserve-indentation t)
  (org-support-shift-select 'always)
  :hook
  (org-mode . turn-on-auto-revert-mode)
  (org-mode . org-cdlatex-mode)
  (org-babel-after-execute . org-redisplay-inline-images))

*** LaTeX previews

Org's built-in =org-latex-preview-mode= automatically toggles previews while editing and previews newly inserted fragments. The personal setting =my-latex-preview-scale= controls image resolution. The =dvisvgm= backend uses pdfLaTeX by default, enabling faster previews through precompilation. Org files can override the compiler with =#+LATEX_COMPILER=; LuaLaTeX and XeLaTeX do not support preview precompilation. The helper in =lisp/latex-preview-config.el= applies the mathematical font and Beamer compatibility additions only once, even when this block is reevaluated. Native Org uses =org-latex-preview-cache= (normally =persist=), not the old =org-preview-latex-image-directory= setting. Existing cache settings are left unchanged.

(require 'latex-preview-config)

*** org-roam

https://www.orgroam.com/

Org Roam is a note-taking tool for networked thought. It's configured to use the notes directory from =personal.org= and provides custom templates for literature notes and projects.

File-node titles should come only from the note itself, not from its =#+setupfile= directives. After enabling this change, run =C-u M-x org-roam-db-sync= once to rebuild existing cached titles.

#+begin_src emacs-lisp
(use-package org-roam
  :straight t
  :after org
  :demand t
  :bind
  (("<f8> f" . org-roam-node-find))
  (("<f8> i" . org-roam-node-insert))
  :custom
  ;; Note: 'my-notes-directory' is set in personal.org
  (org-roam-directory my-notes-directory)
  (org-roam-completion-everywhere t)
  :config
  (require 'org-roam-local-title)
  (require 'literature-notes)
  (advice-add 'org-roam-db--file-title :override #'rvf/org-roam-db-local-file-title)
  ;; Keep a fresh-install index separate from the user's existing database.
  (when (rvf/default-notes-directory-p)
    (setq org-roam-db-location (rvf/local-data-path "org-roam.db")))
  (if (rvf/notes-directory-ready-p)
      (org-roam-db-autosync-mode 1)
    (display-warning 'rvf-personal "Skipping Org Roam autosync: notes directory unavailable" :warning))
  (setq org-roam-capture-templates
        '(("d" "project" plain
           "\n* Goals\n%?\n* Tasks\n\n** TODO Add initial tasks\n\n* Dates\n\n"
           :if-new (file+head "%<%Y%m%d%H%M%S>-${slug}.org"
                              "#+title: ${title}\n#+category: ${title}\n#+filetags: Project")
           :unnarrowed t
           :immediate-finish t)
        ("r" "literature note" plain
         "- tags ::\n- keywords :: \n\n* Org noter notes\n  :PROPERTIES:\n  :Custom_ID: ${citar-citekey}\n  :URL: \n  :AUTHOR: ${citar-author}\n  :NOTER_DOCUMENT: ${rvf/literature-note-document}\n  :NOTER_PAGE:\n  :END:\n\n* ${citar-title}\n\n${rvf/literature-note-footer}"
         :target
         (file+head
          "%(expand-file-name (or citar-org-roam-subdir \"\") org-roam-directory)/${citar-citekey}.org"
          "#+title: ${note-title}\n${rvf/literature-note-setup}")
         :unnarrowed t))))
#+end_src

** Completion and Navigation

This section details the modern completion system composed of Vertico, Orderless, Consult, and Embark.

*** vertico

[[https://github.com/minad/vertico][Vertico]] provides a high-performance, vertical completion UI. It is configured to use =vertico-multiform-mode= to provide an Ido-like experience for file navigation.

#+begin_src emacs-lisp
(use-package vertico

   '((file (:keymap . vertico-directory-map)))))
#+end_src

*** consult

[[https://github.com/minad/consult][Consult]] offers a suite of commands that enhance searching and navigation, such as =consult-line= and =consult-ripgrep=. A custom function, =bms/org-roam-rg-search=, is defined in =lisp/notes-search.el= to search specifically within the Org notes directory (path set in =personal.org=). Use =F5 d= for a case-insensitive search of Org files (including =.org_archive= files) with Consult's live preview. It adds the search options locally through =consult-ripgrep-args=, preserving the normal =F5 r= search and its settings.

#+begin_src emacs-lisp
(use-package consult
  :straight t
  :bind
  ("<f5> d" . bms/org-roam-rg-search)
  ("<f5> l" . consult-line)
  ("<f5> r" . consult-ripgrep)
  :init
  (autoload 'bms/org-roam-rg-search "notes-search" nil t))
#+end_src

*** embark

[[https://github.com/oantolin/embark][Embark]] provides contextual actions for the item-at-point or for completion candidates. A custom Embark action, =my-embark-org-insert-link=, is defined to insert an Org-mode link to a file, bound to =L= in the `embark-file-map`.

#+begin_src emacs-lisp
(use-package embark
  :straight t
  :bind
  (("C-=" . embark-act))
  :config

  ;; For org-mode verbatim text, e.g., =code=
  (sp-local-pair 'org-mode "=" "="

  (sp-local-pair '(org-mode LaTeX-mode) "|" "|"
		 :when '(sp-in-math-p)))
#+end_src
